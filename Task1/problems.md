# Основные проблемы:
- Хранение и обработка персональных данных (ПДн) и медицинской тайны в неконтролируемых файлах. Конфиденциальные данные (ФИО, паспортные данные, история болезни, анализы) хранятся в Excel, JPG, PDF на общем сетевом диске. 

- Доступ к данным ограничен только на уровне доменной аутентификации. Нет ролевой модели (RBAC/ABAC). Бухгалтер, кассир или системный администратор имеют техническую возможность просмотреть медицинские карты любых пациентов.

- Невозможно отследить, кто, когда и какие файлы с ПДн открывал, изменял, копировал или удалял. Нет журналов аудита.

- Внутренние потоки данных между IT-продуктами никак не контролируются. Данные между Excel, 1С и общим диском передаются вручную. Нет регламентированных защищенных каналов и контроля целостности данных, что потенциально ведет к потере актуальности данных, созданию неконтролируемых копий ПДн на рабочих станциях пользователей и впоследствии к утечке.

- Работа 1С в файловом режиме. Файловый режим 1С не предназначен для многопользовательской работы в условиях роста и не обеспечивает надежного разграничения прав и аудита на уровне записей внутри базы.



# Улучшения
## Система тегов

| Категория тега               | Значение тега | Описание                                                          |
| ---------------------------- | ------------- | ----------------------------------------------------------------- |
| Конфиденциальность (уровень) | PUBLIC        | Общедоступные данные, без ограничений.                            |
|                              | INTERNAL      | Внутренние служебные данные, не являющиеся чувствительными.       |
|                              | CONFIDENTIAL  | Конфиденциальные коммерческие или служебные данные.               |
|                              | PII           | Персональные данные, позволяющие идентифицировать лицо.           |
|                              | PHI           | Защищаемая медицинская информация (Protected Health Information). |
|                              | FINANCIAL     | Финансовые и платежные данные.                                    |
| Цель/Домен обработки         | OPERATIONAL   | Данные для операционной деятельности (приём, лечение).            |
|                              | ANALYTICAL_BI | Данные для бизнес-аналитики и отчетности.                         |
|                              | ARCHIVE       | Данные, предназначенные для долгосрочного архивирования.          |
